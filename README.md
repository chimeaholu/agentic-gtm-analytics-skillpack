# Agentic GTM Analytics Skillpack

Agent skills for go-to-market analytics — attribution, forecasting, warehouse
modelling, reporting — across 22 platforms, B2B and B2C.

**It tells you when the number is lying.**

Connectors are free elsewhere. Attribution maths is open source. What this pack
adds is the discipline: it reads the warning fields most integrations ignore,
names the direction of an error rather than hedging, and refuses to promise
capabilities the platform APIs do not have.

## Status

Pre-release. Building toward v1.

## What v1 covers

- Four platforms: PostHog, GA4, Google Ads, Salesforce
- Metric definitions resolved against your existing semantic layer where you have one
- Rule-based attribution on single-source journeys
- An audit that finds where your stack's definitions disagree
- A Salesforce Reports & Dashboards MCP server — a capability no existing server ships
