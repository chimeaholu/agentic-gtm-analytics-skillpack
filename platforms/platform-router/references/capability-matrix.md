# The capability matrix and the auth-cost gradient

Load when a request touches a platform outside the shipped set, or when someone asks what
connecting a platform will get them.

## What each platform can be promised

| Platform | Class | Can an agent create a persistent artefact? |
|---|---|---|
| **salesforce** | authoring-capable | **Yes, a real saved report** via `POST /analytics/reports`. Dashboards **clone only** over that API; authoring from nothing needs the Metadata API. CRM Analytics `/wave/` can create dashboards but is separately licensed. |
| **posthog** | authoring-capable | **Yes.** Insights and dashboards are full CRUD. The only platform where "the agent built you a dashboard" is plainly truthful. |
| looker | authoring-capable | Yes: `create_look`, `create_dashboard`, `create_dashboard_element`, scheduled plans. |
| powerbi | authoring-capable | Classic dashboards and tiles compose directly; reports by clone-and-rebind or PBIR. Capacity and tenant-admin settings gate it. |
| cube-cloud | authoring-capable | Workbooks, reports and dashboards. |
| mixpanel | authoring-capable **via MCP only** | Dashboards and reports through the official MCP, which is beta. **No REST authoring path.** Not a load-bearing guarantee. |
| klaviyo | query-compose | A values-report query whose output the docs promise matches the UI. No visual artefact. |
| tableau | query-compose | **Pulse metric definitions** are full CRUD. **There is no `POST /worksheets`**; dashboard composition from a spec is not a product capability. |
| snowflake | query-compose | Semantic views as definition objects. No dashboard. |
| **ga4** | extract-only | **No.** No API exists for reports, Explorations or dashboards. Explorations have no public API at all. Admin API creates dimensions, audiences, key events and channel groups only. |
| **google-ads** | extract-only | **No.** No saved-report, scheduled-report or dashboard resource. |
| meta-ads | extract-only | No. |
| linkedin-ads | extract-only | No. Also **no pagination** on `adAnalytics` and a 15,000-element cap. |
| hubspot | extract-only | **No.** Report creation does not exist, and there is no endpoint that takes a report id and returns rows. |
| marketo | extract-only | **No reporting API of any kind.** Adobe's own guidance is to extract activities and compute your own numbers. |
| pardot / MCAE | extract-only | No report objects. B2B Marketing Analytics needs a separate CRM Analytics licence. |
| braze | extract-only | No. |
| iterable | extract-only | No. |
| amplitude | extract-only | **No.** Amplitude's own docs say the Dashboard REST API cannot create charts or dashboards. |
| bigquery | extract-only | Warehouse backend; no reporting artefact. |
| segment | extract-only | Schema oracle and pipeline diagnostics. |
| rudderstack | extract-only | Pipeline telemetry and governance. **Transformation deployment is the highest-risk write in the whole research** and is gated hard. |
| Looker Studio | **nothing** | The API does asset search and permission management only. **It cannot read report data, create or modify a report, or read chart configuration.** The Linking API builds a pre-filled URL a human clicks. |

## Things that sound possible and are not

Do not promise any of these. Each is contradicted by the platform research.

- A GA4 dashboard or Exploration built by an agent.
- A Looker Studio report generated by an agent.
- HubSpot report or dashboard creation, or reading a custom report's output.
- Marketo report creation, execution or retrieval, or reproducing Marketo's own report
  numbers, which is structurally impossible because de-duplication and bot filtering are
  undocumented.
- Pardot report objects.
- Amplitude chart or dashboard creation.
- Snowsight dashboard creation.
- Tableau dashboard composition from a specification.
- Salesforce dashboard authoring from nothing over the Reports API.
- Exact GA4 Data API to GA4 UI reconciliation.
- An MCP server for LinkedIn Ads, Segment, Marketo or Pardot. None exists that is worth
  depending on; those modules specify a thin direct client instead.

## The auth-cost gradient

Surface this **before** any connection attempt. A pack that opens with "connect your
platforms" and does not say this gets abandoned at step one.

| Tier | Time to first query | Platforms | The step people miss |
|---|---|---|---|
| Minutes | 2 to 10 min | PostHog, Amplitude, Mixpanel, Iterable, Klaviyo, HubSpot, Braze, Segment, RudderStack, Snowflake, Cube | **Region and host first.** Amplitude EU, Mixpanel EU and IN, Iterable EU, PostHog EU and self-hosted, Braze cluster. The wrong host returns confusing auth errors or silently empty results, not a redirect. Klaviyo also needs the `revision` header on every request. |
| About 30 minutes | 20 to 45 min | GA4, BigQuery, Marketo | **GA4: add the service-account email as a user on the property itself.** Enabling the API in the Cloud project grants nothing. BigQuery needs billing enabled and cost guardrails. Marketo needs an API-only user plus a LaunchPoint custom service, which is admin-only. |
| Hours | 1 to 4 h | Looker, Tableau, Salesforce, Pardot, dbt Platform | Looker on older instances puts the API on port 19999. Tableau PATs expire after 15 idle days and re-signing invalidates the prior session. **Salesforce needs API Enabled, folder access, FLS on every field and a pinned timezone.** Pardot needs the business-unit id header on every call, and the wrong one returns a valid 200 over a different dataset. |
| Hours to days | 4 h to 2 days | Power BI / Fabric | A tenant admin must enable service principals for Power BI APIs and allowlist the group. Ask about capacity before promising anything: XMLA and the Arrow DAX endpoint need Fabric, Premium, Embedded or PPU. |
| Days | 2 to 10 days | Meta Ads, LinkedIn Ads | A human review you cannot accelerate. **Meta: use a System User token, not a user token**, which expires in 60 days and silently breaks scheduled work. LinkedIn has no service-account equivalent; credentials are bound to a person. |
| Days to weeks | 3 days to 3 weeks | **Google Ads** | Tiered, human-reviewed developer-token approval: Test, Explorer, Basic, Standard, each a separate rejectable application. Test tier cannot reach production accounts. Under an MCC, a missing `login_customer_id` produces a misleading `USER_PERMISSION_DENIED`. |

**Auth cost does not correlate with data value.** The two-minute platforms have some of the
best query surfaces in the stack; the multi-week platform has a three-tool read-only MCP.

## What connecting does not buy you

- Connecting **Salesforce** does not get you a reporting MCP. None exists, official or
  community, that wraps the Reports and Dashboards REST API.
- Connecting **HubSpot** does not get you analytics tools.
- Connecting **GA4** does not let you build a GA4 dashboard.
- Connecting an **official vendor MCP** does not get you API parity. Hosted official
  servers are vendor-hosted and versionless: unpinnable, undiffable, and changeable between
  sessions with no changelog. Every module names its direct-API fallback for that reason.
